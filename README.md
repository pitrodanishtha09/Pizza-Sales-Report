# 🍕 Pizza Sales Dashboard

## 📊 Project Summary
An interactive **Power BI dashboard** built to analyze pizza sales data and uncover key business insights.  
Transforms raw sales data into meaningful visuals for **data-driven decision-making**.

---

## 🛠 Tools Used
- **SQL Server** – Data analysis & queries  
- **Power BI** – Dashboard & visualization  
- **DAX** – Calculated measures  

---

## 📁 Dataset Includes
- Order date & time  
- Pizza category & size  
- Quantity sold  
- Price  

---

## 📌 Key KPIs
- 💰 **Total Revenue**
- 🧾 **Total Orders**
- 🍕 **Total Pizzas Sold**
- 📈 **Average Order Value**
- ⏱ **Peak Sales Hours**

---

## 🔍 Dashboard Insights
- Best & worst performing pizzas  
- Sales trends by day & month  
- Revenue by category and size  
- Peak order timings for business optimization  

---

## 🚀 Project Workflow
**Raw Data → SQL Analysis → Data Cleaning → Power BI Dashboard → Business Insights**

---

## 💡 Business Value
- Identify top-selling products  
- Detect low-performing items  
- Optimize staffing based on peak hours  
- Support pricing & promotion decisions
